- [Open Source Observatory (OSOR)](https://interoperable-europe.ec.europa.eu/collection/open-source-observatory-osor): The European Commission's collection/knowledge hub for public sector free and open source software — news, events, a Knowledge Centre, OSPO/open-source-governance guidance, an interactive country resource map, and a newsletter. Currently highlighting the new **EU Open Source Strategy**, part of the European Tech Sovereignty Package, which places open source at the centre of EU technological sovereignty and promotes European open alternatives to non-EU proprietary software. Keywords: OSOR, EU Open Source Strategy, OSPO, public sector FOSS, European Commission. Related: [[Reproducible_Science]], [[OSPO-RADAR]] (private).

- [Public Code Observatory launches during UN Open Source Week](https://interoperable-europe.ec.europa.eu/collection/open-source-observatory-osor/news/public-code-observatory-launches-during-un-open-source-week) (Sofia Linna, published on OSOR, 3 Sept 2026): Software Heritage, UNESCO, and the UN Office for Digital and Emerging Technologies (ODET) launched the **Public Code Observatory** during UN Open Source Week (22–26 June), a global evidence base on open source participation by public institutions. Its first output, *The State of Public Code*, covers roughly 288,400 unique public repositories across all 193 UN member states, built on the Software Heritage Archive (29+ billion source files, ~438 million projects). Key findings: contributor headcount tracks the UN E-Government Development Index more closely than GDP per capita (correlation, not cause); the Americas and Europe hold the largest contributor shares, with growing activity in Australia, Türkiye, Japan, and Singapore; cross-border collaboration remains thin, clustering around a few pairs (UK–US, Australia–US, Brazil–US). Linda drafted a LinkedIn post on this launch (below). Keywords: Public Code Observatory, State of Public Code, UN Open Source Week, Software Heritage, UNESCO, ODET. Related: [[Reproducible_Science]], [[OSPO-RADAR]] (private).

> Open source that governments actually use, mapped for the first time
>
> Open Source Observatory (OSOR) has been the place to track EU public sector open source for years. What's new is the Public Code Observatory, launched during UN Open Source Week (22-26 June) by Software Heritage, UNESCO and the UN Office for Digital and Emerging Technologies. I work in Software Heritage's Open Science division, so I've been watching this one closely.
>
> Its first output, The State of Public Code, replaces assumption with a dataset: (i) roughly 288,400 unique public repositories, (ii) all 193 UN member states represented via government domains, (iii) built on the Software Heritage Archive, over 29 billion source files and 438 million projects.
>
> Two findings are worth sitting with. First, contributor numbers track the UN E-Government Development Index far more closely than GDP per capita, correlation not causation, but it says wealth isn't the main gate to participating in public tech. Second, cross-border collaboration is thin. The Americas hold the largest contributor headcount, Europe the second, and countries like Australia, Türkiye, Japan and Singapore are producing more, but the shared projects that do exist cluster around a handful of pairs (UK-US, Australia-US, Brazil-US). Governments are building in parallel more than they're building together.
>
> That gap is the actual opportunity here. If you work inside a public sector OSPO, or you're deciding whether your government's next platform gets built in the open, what would make you collaborate across a border rather than start from zero again?
>
> Linda Angulo Lopez, 5 September 2026
