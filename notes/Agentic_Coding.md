# Agentic Coding

**Summary**: Agentic coding tools and practices — using LLM-driven coding agents (e.g. Claude Code) to plan, build, and validate technical workflows.
**Last updated**: 2026-09-03

- *Django's contribution-checklist bot, incl. an AI-assistance disclosure field* ([[Open_Source]]): a real-world enforcement example of AI-disclosure-in-code-review, distinct from the Côa project's own workflow above — Django's contribution checklist includes a signed AI-assistance disclosure among several required items, and its CI bot auto-closed Linda's practice PR (run through the tutorial's own worked example, not a real contribution attempt) for an incomplete checklist overall — missing Trac ticket, missing description, and the AI-disclosure box among the gaps, not the AI box alone. See [[Open_Source]] for the full case. Keywords: AI disclosure, Django, CI bot, open source, PR checklist. Related: [[Open_Source]], [[Reproducible_Science]].

- *Côa connectivity pipeline — Claude-generated code under a review-and-disclosure workflow* ([coa-connectivity-lab/eco-connectivity-workflow](https://github.com/coa-connectivity-lab/eco-connectivity-workflow)): A worked case of building a real analysis pipeline with code generated by Claude and kept accountable by process rather than trust — every change goes through a rebased branch and a reviewed pull request, commits are DCO-signed, and each PR must state which files were AI-generated, the prompt or approach, and what a human verified and how. See [[Reproducible_Science]] for the full workflow and its link to the WCRI/GFRN AI-disclosure standard, and [[Conservation]] for the pipeline itself. Keywords: Claude-generated code, AI disclosure, code review, reproducible pipeline. Related: [[Reproducible_Science]], [[Conservation]], [[Python]].
