- *Côa connectivity pipeline — Claude-generated code under a review-and-disclosure workflow* ([coa-connectivity-lab/eco-connectivity-workflow](https://github.com/coa-connectivity-lab/eco-connectivity-workflow)): A worked case of building a real analysis pipeline with code generated by Claude and kept accountable by process rather than trust — every change goes through a rebased branch and a reviewed pull request, commits are DCO-signed, and each PR must state which files were AI-generated, the prompt or approach, and what a human verified and how. See [[Reproducible_Science]] for the full workflow and its link to the WCRI/GFRN AI-disclosure standard, and [[Conservation]] for the pipeline itself. Keywords: Claude-generated code, AI disclosure, code review, reproducible pipeline. Related: [[Reproducible_Science]], [[Conservation]], [[Python]].
